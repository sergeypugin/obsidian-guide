> [!IMPORTANT]
> There are so many hotkeys that people often give up as soon as they start learning them. Understandably, there are hundreds, if not thousands. But here is the important thing: you will need no more than 20. Read more in the [README](../README.md#hotkeys).
# Universal must-haves

> Works in many apps on Windows and Linux; availability may depend on the app and desktop environment.

## Clipboard and text editing

- [ ] `Ctrl + C` / `Ctrl + V` / `Ctrl + X` - copy, paste, cut
- [ ] `Ctrl + Shift + Left / Right (n times)` - select `n` words
- [ ] `Ctrl + Backspace` - delete the previous word
- [ ] `Ctrl + Z` / `Ctrl + Y` or `Ctrl + Shift + Z` - undo the last action / redo it
- [ ] `Ctrl + A` - select everything on the page or in the input field
- [ ] `Ctrl + S` - save the file or document
- [ ] `Ctrl + F` - find a word on the current page
- [ ] `Ctrl + Shift + F` - search the whole app (for example, in IntelliJ IDEA, PyCharm, Code::Blocks, and Obsidian)

## Browsers and some editors

- [ ] `Ctrl + T` - open a new tab
- [ ] `Ctrl + W` - close the current tab or window
- [ ] `Ctrl + Shift + T` - reopen the last closed tab
- [ ] `Ctrl + Tab` / `Ctrl + Shift + Tab` - switch to the tab on the right / left
- [ ] `Ctrl + L` / `Alt + D` - go to the address bar
- [ ] `Alt + Left / Right` - move through the tab's history
- [ ] `F2` - rename a file or folder
- [ ] `F5` - refresh the page

> [!TIP]
> I happened to discover an incredibly versatile shortcut:
> - [ ] `Ctrl + PageUp / PageDown` (on some laptops, `Ctrl + Fn + Up / Down`) - move to the neighboring tab or file in apps that support it
>>- `Up` - the up-arrow key
>>- `Down` - the down-arrow key
>>
>>Adding `Shift` changes "move to" into "move" in apps that support moving tabs or files this way.
> The beauty of this shortcut is that you can add `Shift` to do more, and it works in many apps.

## Desktop

- [ ] `Alt + Tab` - switch to the previous app
- [ ] `Alt + Tab`, then press an arrow key while holding `Alt` - switch between open apps
- [ ] `Ctrl + Shift + Esc` - open Task Manager in Windows; behavior on Linux depends on the desktop environment


# Windows

### Built-in shortcuts

- [ ] `Win + E` - open File Explorer
- [ ] `Win + Arrow` - snap the current window to the left, right, top, or bottom half of the screen
- [ ] `Win + V` - open clipboard history (if enabled)
- [ ] `Win + .` - open the `Emoji and more` panel for emoji and special characters (such as the pound sign, en dash, euro sign, right-arrow symbol, number sign, degrees Celsius, and copyright sign)
- [ ] `Win + L` - lock the computer
- [ ] `Win + Shift + S` - select an area for a screenshot and copy it to the clipboard

### PowerToys shortcuts

[PowerToys](https://github.com/microsoft/PowerToys) is an app with an expanded set of utilities. Of its hotkeys, these are the ones I find especially useful:
- [ ] `Alt + Space` - open PowerToys Run (the default shortcut, which can be changed), where you can:
	- quickly search for an app, file, or folder by name
	- enter `=2+2` and get the result right away
	- enter `)` and copy the time in a format you like
	- type something and open it in your browser
- [ ] `Win + Shift + T` - use Text Extractor to select text on screen and copy the recognized text to the clipboard; results depend on the available OCR language
- [ ] `Win + Ctrl + Shift + D` - switch between dark and light themes

To be honest, PowerToys has too many specialized features. I installed it only for `Alt + Space` and the ability to open any folder in a second.

# Obsidian

Many shortcuts work just like they do in a browser, but Obsidian has some of its own:

- [ ] `Ctrl + E` - switch between reading and editing modes
- [ ] `Ctrl + Click a link` - follow a link
- [ ] `Ctrl + Alt + Left / Right` - go to the previous / next note, as in a browser
- [ ] `Ctrl + O` - find or create a note
- [ ] `Ctrl + P` - open the Command Palette
- [ ] `Ctrl + ;` - add [`properties`](../guides_for_ai/obsidian-properties.md)
- [ ] `Ctrl + G` - open the graph view of your notes
