# Must-have

Перед началом работы всегда важно первым делом настроить "рабочий стол":

> [!WARNING]
> Чтобы ссылки обновлялись автоматически при переименовании файлов, откройте в настройках раздел `Files and links` и включите `Automatically update internal links`.

> [!IMPORTANT]
> Чтобы видеть в дереве файлов слева файлы всех типов, откройте в настройках раздел `Files and links` и включите `Show all file types`.

> [!NOTE]
> Чтобы `PNG`, `GIF` и другие файлы не мешались и хранились в одной папке, откройте в настройках `Files and links` -> `Default location for new attachments`.
> Затем выберите способ хранения вложений.
>
> Обычно я храню вложения в папке, созданной рядом с текущей. Для этого выберите `In the folder specified below` в пункте `Default location for new attachments`. В поле `Attachment folder path` по умолчанию указана папка `Attachments`. Её можно переименовать, но заглавная английская `A` удобна тем, что папка будет ближе к началу списка (если нет папок, названия которых начинаются с `!`, `#`, `_` и подобных символов).

> [!CAUTION]
> Если вы используете `.md`-файлы не только для GitHub, но и для простых заметок в папках Google Диска, то могли заметить, что файл `desktop.ini` постоянно попадается под руку, иногда почти в каждой папке.
>
> Чтобы скрыть его из Obsidian, можно установить плагин `Advanced Exclude` (о нём ниже).

# Плагины

У Obsidian есть свой огромный магазин плагинов. Вот те, которыми мне довелось воспользоваться и которые мне показались полезными:
- `Link Converter`
	Для конвертирования всех вики-ссылок (`[[file]]`) в относительные Markdown-ссылки (`[file](some_path/file.md)`) для всех заметок вашего Vault одной командой. Очень полезно перед публикацией `.md`-файлов на GitHub.
- `Better Export PDF`
	Улучшенный экспортёр заметок в PDF. Позволяет экспортировать целые папки, поддерживает отображение заметок через `![file_name](file_name)`, теги и многое другое. Легко настраивается: можно выбрать формат A4, A5 и другие или создать собственный формат, указать, будет ли отображаться название заметки в PDF, и многое другое.
- `Docxer`
	Плагин для работы с Microsoft Word. Позволяет:
	1. Читать документы без открытия приложения Word (документ открывается в Obsidian меньше чем за секунду, а в Word — за 5-10 секунд).
	2. Конвертировать документы в Markdown с сохранением всех изображений из документа.
- `Excel to Markdown Table`
	Плагин для работы с Microsoft Excel, Google Sheets и прочими не-Markdown таблицами. Позволяет вставлять скопированные таблицы или их части в заметки сразу в виде Markdown-таблиц, не исправляя разметку вручную (можете проверить без плагина, как работает вставка — ломаются разбивки `|-|-|` между заголовками столбцов и строками).
- `Templater`
	Нужен для особой вставки по шаблону: можно использовать конструкции для вставки, например, текущей даты. Мне понадобился только ради ежедневных заметок (встроенный Daily Notes, тот самый значок календарика у вас на панели слева в Obsidian).
- `Kanban`
	Для отображения листов с задачами, демонстрирующих их статус (пример: предстоит, в процессе, прямо сейчас, сделано).
- `Minimal Theme Settings`
	Для изменения темы `Minimal`: использую `Colorful window frame` (подсветка линии вкладок), `Colorful active states` (подсветка текущей заметки) и `Colorful headings` (подсветка заголовков, где красный — заголовок 1-го уровня, а фиолетовый — 6-го).
- `Advanced Exclude`
	Для исключения файлов или папок из вашего Vault. Работает как `.gitignore`, но только, насколько я понял, регистр для него не важен. Я лично использую, чтобы убрать `desktop.ini` от Google и пару моих `*.gscript` файлов для автоматизации работы с Google Календарём. ^6ef345
- `Gemini Scribe`
	Для подключения AI-ассистента Gemini по API key.
	- Репозиторий плагина: [allenhutchison/obsidian-gemini](https://github.com/allenhutchison/obsidian-gemini/)
	- Сайт документации: [Gemini Scribe](https://allenhutchison.github.io/obsidian-gemini/)
	Важно: если вы воспользовались плагином `Advanced Exclude`, чтобы убрать из вашего Vault какие-то папки и файлы, то плагин `Gemini Scribe` их не увидит. Удобно, чтобы изолировать секретное от ИИ. Но это и уберёт те файлы из вашего вида при открытии данного Vault.
- `Plugin Update Tracker`
	Плагин, отслеживающий обновления других плагинов. В случае обновления в вашем правом верхнем углу появится маленький зелёный маячок.

> [!IMPORTANT]
> Если вам понадобится сохранить страницу сайта в Markdown, для этого есть специальное расширение: [Obsidian Web Clipper - Chrome Web Store](https://chromewebstore.google.com/detail/obsidian-web-clipper/cnjifjpddelmedmihgijeibhnjfabmlf).
> 
> Помимо страничек оно работает ещё и с YouTube: скачиваются все таймкоды и субтитры.

# Темы

Многие думают, что главный и единственный плюс тем — это красота.

Однако если у вас уже есть несколько Vault, особенно если в некоторых содержатся похожие заметки, вам придётся переключать у себя в голове контекст, что потребует времени и сил. Чтобы легче было переключаться, можно воспользоваться разными темами, которые будут сигнализировать мозгу о том, где он находится.

Темы, которые я использую:
- `GitHub` — для открытия Vault с папкой для GitHub (удобно для написания `README`-файлов), синий фон и зелёные топики, как на сайте.
- `Primary` — отлично подходит для написания каких-то учебников или подобных книжных вещей. Может, и сгодится для основного Vault. Советую присмотреться из-за множества кастомизаций.
- `Minimal` — спокойная тема, лучший вариант для основного Vault.
