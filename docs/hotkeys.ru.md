# Универсальные Must-Have

> Работают во многих приложениях Windows и Linux; доступность зависит от программы и окружения рабочего стола.

## Буфер обмена и работа с текстом

- [ ] `Ctrl + C` / `Ctrl + V` / `Ctrl + X` — скопировать, вставить, вырезать
- [ ] `Ctrl + Shift + Стрелка влево / вправо (n раз)` — захватить `n` слов
- [ ] `Ctrl + Backspace` — удалить последнее слово
- [ ] `Ctrl + Z` / `Ctrl + Y` или `Ctrl + Shift + Z` — отменить последнее действие / вернуть отменённое
- [ ] `Ctrl + A` — выделить всё на странице или в поле ввода
- [ ] `Ctrl + S` — сохранить файл / документ
- [ ] `Ctrl + F` — поиск слова на текущей странице
- [ ] `Ctrl + Shift + F` — поиск слова во всей программе (для IntelliJ IDEA, PyCharm, Code::Blocks, Obsidian и т.п.)

## Браузер и некоторые редакторы

- [ ] `Ctrl + T` — открыть новую вкладку
- [ ] `Ctrl + W` — закрыть текущую вкладку или окно
- [ ] `Ctrl + Shift + T` — восстановить последнюю закрытую вкладку
- [ ] `Ctrl + Tab` / `Ctrl + Shift + Tab` — переключиться на вкладку справа / слева
- [ ] `Ctrl + L` / `Alt + D` — перейти в адресную строку
- [ ] `Alt + Стрелка влево / вправо` — переход по истории вкладки 
- [ ] `F2` — переименовать файл/папку
- [ ] `F5` — обновить страницу

> [!TIP]
> Совершенно случайно узнал, что существует невероятно универсальное сочетание:
> - [ ] `Ctrl + PageUp / PageDown` (на некоторых ноутбуках — `Ctrl + Fn + Up / Down`) — перейти к соседней вкладке или файлу в приложениях, где это сочетание поддерживается
>>- `Up` — клавиша со стрелкой вверх
>>- `Down` — клавиша со стрелкой вниз
>>
>>В приложениях, где это поддерживается, добавление `Shift` превращает «перейти» в «переместить».
> Прелесть этого сочетания в том, что с помощью `Shift` можно добавить ему новые функции, а работает оно во многих приложениях.

## Рабочий стол

- [ ] `Alt + Tab` — переключение на предыдущую программу
- [ ] `Alt + Tab`, затем стрелка (не отпуская `Alt`) — переключение между запущенными программами
- [ ] `Ctrl + Shift + Esc` — открыть диспетчер задач в Windows; в Linux действие зависит от окружения рабочего стола


# Windows

### Встроенные команды

- [ ] `Win + E` — открыть проводник (Explorer)
- [ ] `Win + Стрелка` — расположить текущее окно на левой / правой / верхней / нижней половине экрана
- [ ] `Win + V` — открыть историю буфера обмена (если она включена)
- [ ] `Win + .` — открыть меню `Emoji and more` с эмодзи и специальными знаками (например, знаком фунта, тире, знаком евро, стрелкой вправо, знаком номера, градусом Цельсия и знаком авторского права)
- [ ] `Win + L` — заблокировать ноутбук
- [ ] `Win + Shift + S` — выбрать область экрана для снимка, который копируется в буфер обмена

### Команды PowerToys

Существует [PowerToys](https://github.com/microsoft/PowerToys) — приложение с расширенным набором утилит. Из всех горячих клавиш особенно полезными мне показались:
- [ ] `Alt + Space` — открыть PowerToys Run (сочетание по умолчанию, его можно изменить в настройках), где можно:
	- быстро найти приложение, файл или папку по имени;
	- написать `=2+2` и получить сразу же результат;
	- написать `)` и скопировать время в любом удобном формате;
	- просто написать что-то, и это откроется в вашем браузере.
- [ ] `Win + Shift + T` — запустить Text Extractor, выделить текст на экране и скопировать распознанный текст в буфер обмена; результат зависит от доступного языка распознавания
- [ ] `Win + Ctrl + Shift + D` — смена темы (тёмная/светлая)

Признаться честно, в PowerToys слишком много специфического функционала. Я установил его только ради `Alt + Space` и возможности открыть любую папку за секунду.

# Obsidian

Тут работают многие сочетания, аналогичные браузерным, но есть и специфические:

- [ ] `Ctrl + E` — переключение режима чтения/редактирования
- [ ] `Ctrl + Клик по ссылке` — переход по ссылке
- [ ] `Ctrl + Alt + Стрелка влево / вправо` — переход на предыдущую/следующую страницу (как в браузере)
- [ ] `Ctrl + O` — найти или создать заметку
- [ ] `Ctrl + P` — открыть палитру команд (Command Palette)
- [ ] `Ctrl + ;` — добавить [`properties`](../guides_for_ai/obsidian-properties.md)
- [ ] `Ctrl + G` — открыть представление заметок в виде графа
