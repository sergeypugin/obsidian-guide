# Must-have

Перед началом работы всегда важно первым делом настроить "рабочий стол":

>[!warning]
>Чтобы ссылки обновлялись автоматически при переименовании файлов, в настройках  перейдите в `Files and links` и переключите тумблер `Automatically update internal links` в состояние `вкл.`

>[!important]
>Чтобы увидеть слева в древе файлов абсолютно все файлы любых расширений, в настройках перейдите по пути `Files and links` и переключите тумблер `Show all files types` в состояние `вкл.`

> [!note]
> Чтобы `PNG`, `GIF` и пр. не мешались и были сложены в одну папку, в настройках перейдите по пути `Files and links` -> `Default location for new attachments`.
Далее выберите свой формат хранения прикрепляемых файлов.
>
> Я храню обычно в папке, которая будет создаваться в той же папке, в которой я работаю. Для этого в `Default location for new attachments` выберите `In the folder specified below`. В появившемся поле `Attachment folder path` по умолчанию стоит папка  `Attachments`, которое Вы можете изменить, однако очень удобно, что она из-за заглавной английской `A` будет в самом верху списка папок (при отсутствии папок, что начинаются с `!`,`#`,`_` и т.п.)

>[!caution]
> Если Вы используете md-файлы не только для гихаба, а, скажем, ещё и для простых заметок внутри Ваших папок из гугл диска, то Вы могли заметить, что у Вас под ногами постоянно болтается `desktop.ini`, причём чуть ли не в каждой папке.
>
> Лучший способ, чтобы его полностью убрать из Вашей Vault, - установить плагин `Advanced Exclude` (про него ниже)

# Плагины

У `Obsidian` есть свой огромный магазин плагинов. Вот те, которыми мне довелось воспользоваться и которые мне показались полезными:
- `Link Converter`
	Для конвертирования всех вики-ссылок (`[file](file.md)`) в относительные `markdown`-ссылки (`[file](some_path/file.md)`) для всех заметок Вашей `Vault` одной командой. Очень полезно перед публикацией `md`-файлов в `GitHub`
- `Better Export PDF`
	Улучшенный экспортер заметок в `pdf`. Позволяет экспортировать целые папки, поддерживает отображение заметок через `![file_name](file_name)`, теги и многое другое. Легко настраиваемо: можно выбрать формат A4, A5 и пр. или даже сделать свой, указать, будет ли отображатся  название заметки в `pdf`, и многое другое
- `Docxer`
	Плагин для работы с `Microsoft Word`. Позволяет:
	1. Читать документы без открытия приложения  `Word` (открыть в `Obsidian` - менее секунды, а вот открыть `Word` - секунд 5-10)
	2. Конвертировать документы в `markdown` с сохранением всех изображений из документа
- `Excel to Markdown Table`
	Плагин для работы с `Microsoft Excel`, `Google Sheets` и прочими не md-таблицами. Позволяет вставлять в заметки скопированные таблицы или их части без проблем вёрстки сразу в md-таблицы (можете проверить без плагина, как работает вставка - ломаются разбивки  `|-|-|` между заголовками столбцов и строками)
- `Templater`
	Нужен для особой вставки по шаблону: можно использовать конструкции для вставки, например текущей даты. Мне понадобился только ради ежедневных заметок (встроенный Daily Notes, тот самый значок календарика у вас в панели слева в `Obsidian`)
- `Kanban`
	Для отображения листов с задачами, демонстрирущие их статус (пример: предстоит, в процессе, прямо сейчас, сделано)
- `Minimal Theme Settings`
	Для изменения темы `Minimal`: использую `Colorful window frame` (подсветка линии вкладок), `Colorful active states` (подсветка текущей заметки) и `Colorful headings` (подсветка заголовков, где красный - заголовок 1-го уровня, а фиолетовый - 6-го)
- `Advanced Exclude`
	Для исключения файлов или папок из Вашей Vault. Работает как `.gitignore`, но только насколько я понял, регистр для него не важен. Я лично использую, чтобы убрать `desktop.ini` от гугла и пару моих `*.gscript` файлов для автоматизации работы с гугл календарём ^6ef345
- `Gemini Scribe`
	Для подключения через API Key AI-ассистента Gemini.
	- Репозиторий плагина: [allenhutchison/obsidian-gemini](https://github.com/allenhutchison/obsidian-gemini/)
	- Сайт документации: [Gemini Scribe](https://allenhutchison.github.io/obsidian-gemini/)
	Важно: если Вы воспользовались плагином `Advanced Exclude`, чтобы убрать из Вашей `Vault` какие-то папки и файлы, то плагин `Gemini Scribe` их не увидит. Удобно, чтобы изолировать секретное от ИИ. Но это и уберёт те файлы и из вашего вида при открытии данной `Vault`.
- `Plugin Update Tracker`
	Плагин, отслеживающий обновления других плагинов. В случае обновления, в Вашем правом углу появится маленький зелёный маячок

>[!important]
> Если Вам когда-то понадобиться конвертировать страничку сайта в `markdown`, то есть специальное расширение для этого - [Obsidian Web Clipper - Chrome Web Store](https://chromewebstore.google.com/detail/obsidian-web-clipper/cnjifjpddelmedmihgijeibhnjfabmlf).
> 
> Помимо страничек оно работает ещё и с `youtube`: скачиваются все таймкоды и субтитры
# Темы

Многие думают, что главный и единственный плюс тем - это красота.

Однако если у Вас уже несколько `Vault` и если ещё и в некоторых содержатся похожие замекти, Вам придётся переключать у себя в голове контекст, что потребует время и силы. Чтобы легче было переключаться, можно воспользоваться разными темами, которые будут сигнализировать мозгу о том, где он находится.

Темы, которые я использую:
- `GitHub`- для открытия Vault с папкой для GitHub (удобно для написания `README`-файлов), синий фон и зелёные топики как на сайте
- `Primary` - отлично подходит для написания каких-то учебников или подобных книжных вещей. Может и сгодится для основной Vault. Советую присмотреться из-за бесчисленных кастомизаций)
- `Minimal` - спокойная тема, лучший вариант для основной Vault
